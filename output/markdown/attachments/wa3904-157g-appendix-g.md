# GENERAL ASSISTANCE PROGRAM 

# **City of Waterville** 

# **APPENDIX G 2024 – 2025 Mileage Rate** 

This municipality adopts the State of Maine travel expense reimbursement rate as set by the Office of the State Controller. The current rate for approved employment and necessary medical travel, etc. is $0.50 per mile. 

Please refer to the Office of State Controller for changes to this rate: Telephone: 626-8420 or visit: http://www.state.me.us/osc/
